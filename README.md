# 뭐든지 랜덤

고민될 때 가볍게 사용할 수 있는 브라우저 기반 랜덤 생성기 모음입니다. 회원가입이나 설치 없이 웹페이지를 열어 바로 사용할 수 있습니다.

## 이용하기

- **웹사이트:** https://tony1010-dev.github.io/random/
- **GitHub 저장소:** https://github.com/tony1010-dev/random

## 주요 기능

현재 19가지 도구를 제공합니다.

- 영어 이름과 닉네임 생성
- 반려견·반려묘 이름 추천
- 점심 메뉴, 카페 메뉴, 여행지 추천
- 오늘의 옷차림 추천
- 투폰 뒷자리와 이메일 주소 생성
- 팀·프로젝트 이름 생성
- 제비뽑기와 팀 나누기
- 비밀번호 생성 및 패턴 추천
- 로또 번호와 랜덤 숫자 생성
- 랜덤 색상 생성
- 아이스브레이킹 질문

## 사용 방법

1. [웹사이트](https://tony1010-dev.github.io/random/)에 접속합니다.
2. 왼쪽 메뉴에서 원하는 도구를 선택합니다.
3. 조건을 선택하고 **뽑기** 버튼을 누릅니다.
4. 복사 버튼으로 결과를 복사할 수 있습니다.

## 직접 실행하기

저장소를 내려받은 뒤 최상위 `index.html`을 브라우저에서 열면 됩니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

```bash
git clone https://github.com/tony1010-dev/random.git
cd random
```

## 파일 구성

```text
.
├── index.html          # GitHub Pages 진입 페이지
└── random/
    ├── index.html      # 랜덤 생성기 화면
    ├── app.js          # 기능과 데이터
    ├── styles.css      # 화면 스타일
    └── logo.png        # 로고 이미지
```

## 데이터와 개인정보

랜덤 결과는 브라우저에서 생성됩니다. 입력한 값은 서버로 전송하거나 저장하지 않습니다. 비밀번호 생성 결과는 중요한 계정에 사용하기 전에 직접 안전성을 확인해 주세요.

## 배포

GitHub Pages는 `main` 브랜치의 변경 사항을 자동으로 배포합니다. 최상위 `index.html`은 실제 앱 파일이 있는 `random/` 폴더를 불러옵니다.
